# 코딩 제출실 설치 안내 (약 5분)

학생 제출물과 선생님 피드백은 **선생님 구글 드라이브의 구글 시트 한 개**에 저장돼요. 따로 서버나 비용이 필요 없어요.

## 1. 구글 시트 만들기
1. drive.google.com에서 **새로 만들기 → Google 스프레드시트**. 이름은 `코딩제출실_2026` 정도로 지어 주세요.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.

## 2. 코드 붙여넣기
1. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣어요.
2. 맨 위 줄의 `TEACHER_KEY = '여기에_교사_비밀번호를_적으세요'`를 선생님만 아는 비밀번호로 바꿔요.
3. 저장(디스크 아이콘 또는 Ctrl+S).

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴에서 유형 **웹 앱** 선택
3. 실행 사용자: **나**, 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 승인(“고급 → 안전하지 않은 페이지로 이동”이 나오면 선생님 계정이 직접 만든 스크립트라 괜찮아요)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.

## 4. 사이트에 주소 넣기
`python_basic/assets/config.js`의 `API_URL: ""` 따옴표 안에 복사한 주소를 붙여넣고 GitHub에 저장(커밋)하면 끝이에요.
화면 위의 노란 **체험 모드** 표시가 사라지면 연결된 거예요.

## 수업에서 쓰기
- 학생: `…/python_basic/submit.html` (각 수업 페이지 맨 아래 ‘과제 제출하기’ 버튼과 연결돼 있어요)
- 선생님: `…/python_basic/teacher.html` → 2단계에서 정한 비밀번호

## 알아 두면 좋은 점
- 시트에는 `students`, `submissions`, `reports` 탭이 자동으로 생겨요. 시트에서 직접 점수를 보거나 내려받을 수도 있어요.
- Apps Script 코드를 고쳤다면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영돼요. (주소는 그대로예요)
- 학생이 비밀번호를 잊으면 교사 화면 **학생 관리 → 비밀번호 초기화**를 눌러 주세요. 제출물은 그대로 남아요.
- 스스로 하기 기록(붙여넣기 차단, 다른 창 이동, 타자 과정)은 브라우저에서 할 수 있는 범위의 **참고 지표**예요. 휴대폰으로 AI를 보고 따라 치는 것까지 막지는 못해요. 그래서 ‘생각 먼저’ 계획, ‘가장 중요한 줄’ 설명, 타자 과정 재생을 함께 보고, 수치가 낮은 학생과는 코드에 대해 짧게 이야기 나눠 보는 것을 권해요.
