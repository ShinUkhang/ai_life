💡 선생님의 친절한 수학 설명 (어떤 셀을 빼야 할까?):
1. 픽셀화와 행렬(Matrix): 컴퓨터 화면은 작은 바둑판 칸(픽셀)들로 이루어져 있습니다. 검은색은 0, 흰색은 255라는 숫자로 기억합니다.
2. 뺄셈 위치에 따른 테두리 방향:
  • 👉 오른쪽 셀과의 뺄셈 (가로 방향): |오른쪽 셀(r, c+1) - 현재 셀(r, c)| ➡️ 좌우 밝기가 바뀔 때 큰 숫자가 나와 '세로선(수직 테두리)'을 감지합니다.
  • 👇 아래쪽 셀과의 뺄셈 (세로 방향): |아래쪽 셀(r+1, c) - 현재 셀(r, c)| ➡️ 상하 밝기가 바뀔 때 큰 숫자가 나와 '가로선(수평 테두리)'을 감지합니다.
  • ✨ 종합 테두리: max(오른쪽 차이, 아래쪽 차이) ➡️ 세로선과 가로선이 합쳐져 완전한 물체 외곽선이 완성됩니다!
3. 임계값(Threshold): "차이가 몇 이상이어야 진짜 테두리로 인정할까?"를 결정하는 기준 숫자입니다.
🎨 8×8 픽셀 캔버스 (도화지)
마우스로 칸을 클릭하거나 드래그하여 흰색(255)을 칠해보세요.
0 = 검정 (어두움) 255 = 흰색 (밝음)
🔢 컴퓨터의 뇌: 8×8 숫자 행렬 (밝기 0~255)
실시간 숫자 동기화
👆 실시간 뺄셈 검사기: 위 행렬 표의 칸에 마우스를 올리면 [현재 셀]과 [👉 오른쪽 셀], [👇 아래쪽 셀]의 뺄셈 계산 과정이 여기에 표시됩니다.
✨ 값 차이(뺄셈)로 찾은 테두리
테두리: 0개
경계면에서 |이웃 픽셀 뺄셈|을 수행하여 찾은 테두리입니다.
초록 = 테두리 픽셀 검정 = 배경

# [파이썬 실습] 픽셀 이웃 뺄셈 테두리 검출 & 움직임 감지 배경 차분(MOG2) 카운터
# 🎒 이 코드는 위 시뮬레이터가 화면 뒤에서 하던 일을 파이썬으로 옮긴 것입니다.
#    Colab 노트북 '실습)_물체_인식.ipynb'의 셀들과 같은 내용이니, 한 줄씩 실행하며 비교해보세요!
import cv2
import numpy as np
셀 2 · 픽셀 이웃 뺄셈 테두리 검출 
# 1. 픽셀 이웃 뺄셈을 통한 테두리(Edge) 찾기 (수학적 원리)
#    - 1단계 시뮬레이터에서 마우스로 직접 해본 '오른쪽 셀/아래쪽 셀 뺄셈'이 바로 이 함수예요.
def detect_edges_by_difference(gray_image, threshold=30):
    # 가로(오른쪽 셀) 뺄셈: 세로선 감지
    diff_right = np.abs(gray_image[:, 1:].astype(int) - gray_image[:, :-1].astype(int))
    # 세로(아래쪽 셀) 뺄셈: 가로선 감지
    diff_down = np.abs(gray_image[1:, :].astype(int) - gray_image[:-1, :].astype(int))
    
    # 임계값(Threshold) 비교
    edge_right = (diff_right >= threshold) * 255
    edge_down = (diff_down >= threshold) * 255
    return edge_right.astype(np.uint8), edge_down.astype(np.uint8)
셀 3 · 움직임 감지 배경 차분(MOG2) 카운터 
# 2. 고속도로 영상 움직임 감지 & 차량/오토바이 선 통과 카운터
#    - 3단계 시뮬레이터의 '최소 크기 슬라이더'가 바로 이 함수의 min_area예요.
#    - 배경 차분: 멈춰 있는 '배경 화면'을 미리 기억해두고 현재 화면에서 빼는 방법이에요.
#      차이가 나는 부분(움직인 물체)만 흰색 덩어리로 남습니다.
def process_traffic_video(video_path="car_highway2.mp4", min_area=350, line_ratio=0.65):
    cap = cv2.VideoCapture(video_path)
    # 배경 차분기: '움직임 흑백 화면'을 만드는 도구예요. 배경과 다른 픽셀만 흰색으로 표시해줍니다.
    fgbg = cv2.createBackgroundSubtractorMOG2(history=500, varThreshold=50, detectShadows=False)
    
    passed_count = 0
    
    while cap.isOpened():
        ret, frame = cap.read()
        if not ret: break
        
        h, w = frame.shape[:2]
        line_y = int(h * line_ratio)
        
        # 흑백 마스크 생성 및 노이즈 제거
        fgmask = fgbg.apply(frame)
        kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
        fgmask = cv2.morphologyEx(fgmask, cv2.MORPH_OPEN, kernel)
        
        # 흰색 덩어리들의 외곽선 검출 (덩어리 하나하나의 윤곽을 찾습니다)
        contours, _ = cv2.findContours(fgmask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
        
        for cnt in contours:
            area = cv2.contourArea(cnt)
            # ⭐ 크기 필터링: 덩어리의 넓이가 min_area보다 클 때만 '진짜 물체'로 인정!
            #    (작게: 오토바이 포함 / 크게: 자동차만)
            if area >= min_area:
                x, y, cw, ch = cv2.boundingRect(cnt)
                cy = y + ch // 2
                
                # 통과선 통과 판정
                if abs(cy - line_y) < 6:
                    passed_count += 1
                
                # 초록색 인식 네모 상자 그리기
                cv2.rectangle(frame, (x, y), (x + cw, y + ch), (0, 255, 0), 2)
        
        # 통과선(노란색 선) 및 카운트 표시
        cv2.line(frame, (0, line_y), (w, line_y), (0, 255, 255), 2)
        cv2.putText(frame, f"Count: {passed_count}", (20, 40), cv2.FONT_HERSHEY_SIMPLEX, 1.2, (0, 0, 255), 3)
    
    cap.release()
    print(f"최종 통과 카운트: {passed_count}대")
