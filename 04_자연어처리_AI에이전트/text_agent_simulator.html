💡 선생님과 함께 짚고 가는 기초 개념:
1. LLM (거대 언어 모델): 수억 개의 책과 글을 읽고 학습하여 인간처럼 말을 이해하고 다음 단어를 자연스럽게 이어 쓰는 거대한 언어 두뇌입니다.
2. AI 에이전트 (AI Agent): 단순한 챗봇을 넘어, '목표(Goal)'를 가지고 주변 문서나 환경을 '탐색(Search)'하고 '판단(Reason)'한 뒤, 스스로 '행동(Act)'하는 자율적인 인공지능입니다.
3. 토큰화 (Tokenization): 컴퓨터는 한글 글자를 그대로 이해하지 못합니다. 따라서 문장을 '의미 있는 작은 조각(토큰)'으로 쪼개고 각각 고유한 '숫자 번호표(ID)'를 부여해야 합니다.

💡 문장과 문장의 관련성을 '각도(Angle)'로 재는 원리 (코사인 유사도):
1. 화살표(벡터) 그리기: 문장에 나온 핵심 단어들의 빈도를 세어 2차원 공간 위의 화살표로 나타냅니다.
2. 사잇각과 코사인 수식: 두 문장의 의미가 비슷하면 두 화살표는 거의 같은 방향을 가리켜 사잇각 θ가 0°에 가까워집니다.
  • cos(0°) = 1.0 : 완벽하게 같은 주제!
  • cos(90°) = 0.0 : 전혀 상관없는 딴소리!
3. 유사도 공식: 유사도 = cos(θ) = (A · B) / (||A|| × ||B||)

셀 1 · 라이브러리 불러오기 
# [파이썬 실습] 토큰화, 코사인 유사도 기반 RAG(검색 증강 생성) 및 Gemini API 연동 에이전트
# 💡 위에서 체험한 '토큰화 → 벡터 → 코사인 유사도 → RAG 에이전트' 과정을 파이썬 코드로 그대로 옮긴 것입니다.
import numpy as np
셀 2 · 토큰화 & 어휘 사전 만들기 
# 📚 코퍼스(corpus): 에이전트가 읽을 '책' = 문장들의 모음
# 1. 문장 토큰화 및 어휘 사전(Vocab) 만들기
corpus = [
    "동백꽃이 붉게 피어나는 봄날이었다",
    "점순이는 나에게 구운 감자 세 개를 건넸다",
    "너희 집엔 이거 없지 라며 생색을 냈다",
    "나는 화가 나서 감자를 발로 툭 차버렸다"
]

vocab = sorted(list(set(" ".join(corpus).split())))
word_to_id = {w: i for i, w in enumerate(vocab)}
셀 3 · Bag-of-Words 벡터화 
# 2. Bag-of-Words 문장 벡터화
def text_to_vector(text):
    # 문장을 단어 빈도 벡터로 바꾸는 함수: 각 단어가 몇 번 나왔는지 셉니다
    vec = np.zeros(len(vocab))  # 단어 사전 크기만큼 0으로 채운 빈 리스트 준비
    for word in text.split():
        if word in word_to_id:
            vec[word_to_id[word]] += 1  # 사전에 있는 단어라면 해당 칸의 숫자를 1 올리기
    return vec
셀 4 · 코사인 유사도 계산 
# 💡 코사인 유사도 = 두 화살표가 같은 방향을 볼수록 1에 가까워지는 '관련성 점수'
# 3. 코사인 유사도: cos(theta) = (A · B) / (||A|| * ||B||)
def cosine_similarity(v1, v2):
    norm1 = np.linalg.norm(v1)  # 화살표 A의 길이
    norm2 = np.linalg.norm(v2)  # 화살표 B의 길이
    if norm1 == 0 or norm2 == 0: return 0.0  # 길이가 0이면 0으로 나누는 오류 방지
    return float(np.dot(v1, v2) / (norm1 * norm2))
셀 5 · RAG 근거 문장 검색 
# 4. 사용자 질문에 가장 관련 깊은 근거 문장 검색 (RAG 검색기)
query = "점순이가 건넨 선물은 무엇인가?"  # 🙋 학생의 질문
q_vec = text_to_vector(query)

scores = [cosine_similarity(q_vec, text_to_vector(doc)) for doc in corpus]
best_doc_idx = int(np.argmax(scores))  # 점수가 가장 높은 문장의 번호 찾기
print(f"질문: {query}")
print(f"가장 유사한 원문 근거: \"{corpus[best_doc_idx]}\" (유사도: {scores[best_doc_idx]:.3f})")
셀 6 · Gemini 프롬프트 조립 
# 5. Gemini LLM에게 캐릭터 페르소나와 근거 문장을 결합하여 전달
# 🧠 AI 두뇌에게 줄 '조립된 지시문(프롬프트)': 근거 + 질문 + 말투를 한 번에 전달!
prompt = f"""
당신은 소설 '동백꽃'의 '점순이'입니다.
[참고할 원문 근거]: {corpus[best_doc_idx]}
[질문]: {query}
점순이의 톡톡 쏘는 새침데기 말투로 위 근거에 기반하여 대답해주세요.
"""
print(f"\n최종 조립된 에이전트 프롬프트:\n{prompt}")
# ✅ 여기까지 따라오면: 질문과 가장 관련 있는 원문 문장을 스스로 찾아내는 RAG 검색기 완성!
