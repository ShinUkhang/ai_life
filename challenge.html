하고 싶은 과제를 하나 골라요. 큰 문제를 작은 단계로 나눠 두었으니, 쉬워 보여도 한 단계씩 생각을 적으며 풀어요. 막히면 오류 검사와 힌트가 도와줘요.

1문제 읽기

단계마다 자동으로 확인해요

4돌아보기

막힌 곳과 배운 점을 적어요

5제출

기록 파일과 보고서를 올려요

적은 내용과 코드는 이 컴퓨터의 브라우저에만 저장돼요. 다른 컴퓨터에서 이어서 하려면 기록 파일을 내려받아 두세요.

1. 문제 읽기

완성하면 이렇게 나와요
막히면 다시 볼 자료

2. 손으로 먼저

코드를 쓰기 전에, 작은 예를 머리와 손으로 직접 풀어 봐요. 컴퓨터에게 시킬 일을 내가 먼저 해 보는 거예요.

3. 한 단계씩 코드 쓰기

먼저 위의 '문제를 내 말로 쓰기'(10자 이상)와 '손으로 먼저'를 끝내면 열려요.
이렇게 해 보세요. 한 단계의 목표만 보고 코드를 조금 쓴 뒤 ▶ 실행으로 확인해요. 오류가 나면 '오류 검사'를 눌러 어느 줄이 문제인지 먼저 찾아봐요. 다 되면 '이 단계 확인'을 눌러요.

4. 돌아보고 제출하기

모든 단계를 통과하면 열려요.
