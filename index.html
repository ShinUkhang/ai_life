AI는 마법이 아니라 숫자와 규칙입니다. 변수 하나를 바꾸고, 결과를 먼저 예측하고, 왜 그렇게 됐는지 코드로 설명하는 8번의 탐구 수업이에요. 설치 없이 브라우저만 있으면 돼요.

1차시부터 시작 → 전체 차시 보기 수업 방식
8차시파이썬 브라우저 실행코랩 연동활동지 자동 저장
learn.py — 학습 = 오차 줄이기
W = 1.50      # 기울기 ← 아래 슬라이더
b = 0.50      # 절편

for x, y in data:          # 점 8개
    pred = W * x + b        # AI의 예측
    err += (y - pred) ** 2  # 틀린 정도

print("MSE =", err / len(data))
>>> MSE = 0.00
