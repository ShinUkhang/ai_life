💡 왜 가중치 부호가 서로 다를까요?
• 세로선 필터(1~2번): 숫자 1의 고유 특징이므로 양수 가중치(+3)를 곱해 점수를 올립니다.
• 가로선 및 대각선 필터(3~6번): 숫자 2의 고유 특징이므로 음수 가중치(-3)를 곱해, 이 모양이 있으면 점수를 크게 깎아 '숫자 2'로 판별되게 합니다!

🔍 1. CNN(합성곱 신경망)이란 무엇인가요?

기존의 일반 인공신경망(MLP)은 2차원 이미지를 1줄로 길게 펼쳐서 입력받았기 때문에, 픽셀들 사이의 상하좌우 공간적 관계(선, 모서리, 모양)가 파괴되는 심각한 단점이 있었습니다.

CNN(Convolutional Neural Network)은 사람이 눈으로 사물을 볼 때 윤곽선이나 특징을 먼저 파악하는 원리를 본떠, 작은 필터(커널)를 이미지 전체에 슬라이딩(합성곱)시키며 위치와 상관없이 사물의 고유한 특징을 찾아내는 혁신적인 인공지능 구조입니다.

핵심 비유 돋보기로 그림 훑어보기: 3×3 크기의 작은 돋보기를 들고 6×6 그림의 왼쪽 위부터 오른쪽 아래까지 1칸씩 이동하며, 돋보기 속의 모양(세로선, 가로선 등)과 일치하는 부분이 어디에 있는지 찾아 점수로 기록하는 과정이 바로 합성곱(Convolution)입니다!

📐 2. 단계별 수학 계산 공식 총정리

① 2차원 합성곱 연산 (Convolution 2D)

입력 이미지 \(I\)의 위치 \((i, j)\)에서 \(3\times 3\) 커널 \(K\)와의 합성곱 결과 \(O(i, j)\)는 대응하는 원소끼리 곱한 뒤 모두 더한 값입니다:

\[ O(i, j) = \sum_{m=0}^{2} \sum_{n=0}^{2} I(i+m, j+n) \times K(m, n) \]

입력 크기가 \(6\times 6\), 필터 크기가 \(3\times 3\), 보폭(Stride)이 1, 패딩(Padding)이 0일 때, 출력 특성맵의 크기는 \((6 - 3) + 1 = 4\times 4\)가 됩니다.

② 맥스풀링 (Max Pooling 2×2)

\(4\times 4\) 특성맵을 \(2\times 2\) 크기의 4개 구역으로 나누고, 각 구역에서 가장 큰 값(최대값) 하나만 남깁니다:

\[ P(r, c) = \max_{m \in \{0,1\}, n \in \{0,1\}} O(2r+m, 2c+n) \]

이를 통해 계산량은 75% 감소하고, 글씨의 위치가 살짝 삐뚤어지거나 이동해도 가장 강한 특징을 안정적으로 감지할 수 있게 됩니다(위치 불변성).

③ 완전연결층(Dense Layer)과 최종 판별 공식

추출된 8차원 특징 벡터 \(X = [x_1, \dots, x_8]\)에 학습된 가중치 벡터 \(W\)를 곱하고 편향 \(b\)를 더합니다:

\[ \text{Score} = X \cdot W + b = \sum_{i=1}^{8} (x_i \times w_i) + b \] \[ \hat{Y} = \begin{cases} 1 & \text{if } \text{Score} \ge 0 \\ 2 & \text{if } \text{Score} < 0 \end{cases} \]

셀 1 · 라이브러리 불러오기 
# [파이썬 실습] 순수 NumPy 기반 6x6 손글씨(1 vs 2) CNN 분류 파이프라인
import numpy as np
셀 2 · 합성곱 함수 정의 
# 1. 2D 합성곱 (Convolution: 6x6 -> 4x4)
def conv2d(image, kernel):
    h, w = image.shape
    kh, kw = kernel.shape
    out = np.zeros((h - kh + 1, w - kw + 1))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = np.sum(image[i:i+kh, j:j+kw] * kernel)
    return out
셀 3 · 맥스풀링 함수 정의 
# 2. 2D 맥스풀링 (Max Pooling 2x2, Stride=2: 4x4 -> 2x2)
def max_pool2d(feature_map, pool_size=2):
    h, w = feature_map.shape
    out = np.zeros((h // pool_size, w // pool_size))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = np.max(feature_map[i*pool_size:(i+1)*pool_size, j*pool_size:(j+1)*pool_size])
    return out
셀 4 · 4종 특징 필터 정의 
# 3. 4종 특징 필터 정의 (세로, 가로, 대각선 2종)
kernels = [
    np.array([[0, 1, 0], [0, 1, 0], [0, 1, 0]]),  # 1) 세로선 필터 (|)
    np.array([[0, 0, 0], [1, 1, 1], [0, 0, 0]]),  # 2) 가로선 필터 (-)
    np.array([[1, 0, 0], [0, 1, 0], [0, 0, 1]]),  # 3) 대각선 필터 (\)
    np.array([[0, 0, 1], [0, 1, 0], [1, 0, 0]])   # 4) 역대각 필터 (/)
]
셀 5 · 완전연결층 가중치와 편향 
# 4. 완전연결층 가중치 및 편향
weights = np.array([3.0, 3.0, -3.0, -3.0, -2.0, -2.0, -1.0, -1.0])
bias = 5.0
셀 6 · 순전파 및 최종 판별 
# 5. 순전파 및 최종 숫자 판별 함수
def predict_digit(image_6x6):
    norm_img = image_6x6 / 255.0  # 정규화
    flat_vector = []
    
    for k in kernels:
        fmap = conv2d(norm_img, k)
        pooled = max_pool2d(fmap)
        flat_vector.extend([pooled[0, 0], pooled[1, 1]]) # 대표 특징 추출
        
    flat_vector = np.array(flat_vector)
    score = np.dot(weights, flat_vector) + bias
    prob_1 = 1 / (1 + np.exp(-score))  # 시그모이드 확률
    
    label = 1 if score >= 0 else 2
    return label, score, prob_1
