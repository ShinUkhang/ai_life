AI는 공정할까?

AI는 사람처럼 감정이 없으니 공정할 것 같지만, AI가 배우는 정답은 결국 과거 사람들의 기록입니다. 오늘은 과거 장학생 선발 기록으로 학습한 AI를 직접 만들고, 변수를 바꿔 가며 편향이 어디서 들어오고 어디로 숨는지 추적합니다.

실험 설계

진짜 데이터로는 "편견이 있었는지" 확인하기 어렵기 때문에, 규칙을 우리가 정한 가상의 지원자 2000명으로 실험합니다. 과학 실험처럼 변인을 통제할 수 있어요.

무엇코드에서의 규칙AI가 볼 수 있나?
진짜 실력skill ~ 정규분포(0, 1) — A, B 그룹 똑같이❌ 못 봄
시험 점수score = skill + 운(잡음)✅
사는 동네PROXY 확률로 그룹과 같은 동네✅
그룹 (A/B)30%가 B그룹USE_GROUP가 True일 때만
과거 선발 기록skill + 운 − HISTORY_BIAS × (B그룹이면 1) > 0✅ AI가 배우는 "정답"

AI는 1차시처럼 경사하강법으로 가중치를 학습하는 로지스틱 회귀예요. 가중치가 음수인 정보는 선발에 불리하게 작용합니다.

두 가지 잣대 — 정확도 = AI가 과거 기록과 얼마나 같게 판단했나 / 자격 있는데 탈락한 비율 = 진짜 실력이 기준 이상인데 떨어진 학생의 비율 (현실에서는 알기 어려운 값!)

M1정확도 ≠ 공정성기본

HISTORY_BIAS를 1.0 → 0.0

힌트
정확도는 "과거 기록을 얼마나 잘 따라 했나"예요. 과거 기록이 편견을 담고 있으면, 편견까지 잘 따라 할수록 정확도가 높아집니다. 편견이 있을 때 '그룹' 가중치는 −2 근처, 없을 때는 0 근처예요. AI는 우리가 준 정답을 그대로 배웁니다.
M2그룹 정보를 지우면 해결될까?핵심

HISTORY_BIAS = 1.0으로 돌리고 USE_GROUP을 True → False

힌트
'사는동네'가 그룹과 90% 겹치기 때문에 AI가 동네를 그룹의 대리 변수(proxy)로 써요. 가중치가 약 −0.5에서 약 −1.8로 커집니다. 민감한 열을 지우는 것만으로는 편향이 사라지지 않고 숨을 뿐이에요.
M3대리 변수의 힘심화

USE_GROUP = False 그대로 PROXY를 0.9 → 0.7 → 0.5

힌트
PROXY = 0.5이면 동네와 그룹이 아무 관계가 없어서 AI가 그룹을 추측할 수 없어요. 그러면 선발률 차이가 거의 사라지지만 정확도(과거 기록과의 일치)는 조금 떨어집니다. 현실의 대리 변수 예: 이름, 출신 학교, 우편번호, 사용하는 단어, 취미…
M4코드 수정: 그룹별 기준선코딩 도전

pick = prob >= THRESHOLD 줄을 고쳐 B그룹에는 다른 기준 THRESHOLD_B를 적용해 보세요. 선발률 차이를 10%p 안으로 줄이려면 THRESHOLD_B는 얼마여야 할까?

힌트
THRESHOLD_B = 0.15
pick = np.where(group == 1, prob >= THRESHOLD_B, prob >= THRESHOLD)
차이는 줄지만 "과거 기록과의 정확도"는 내려가요. 무엇을 정답으로 볼지가 결국 사람의 선택이라는 뜻입니다.
