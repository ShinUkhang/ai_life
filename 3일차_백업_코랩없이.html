📚 핵심 개념

1️⃣ 합성곱 (Convolution)

3×3 필터(커널)를 이미지 위에서 밀면서 각 위치마다 곱하고 더하기를 합니다.

세로선 필터 → 세로선만 강조된 특성맵이 나옵니다!

2️⃣ 맥스풀링 (Max Pooling)

2×2 영역에서 가장 큰 값만 남깁니다. 크기는 절반, 특징은 유지!

3️⃣ 완전연결층 (Dense)

평탄화한 벡터에 가중치를 곱하고 더해서 최종 점수를 냅니다.

4️⃣ 시그모이드

점수를 0~100% 확률로 바꿔줍니다.

💻 핵심 코드 (백업 실행기에 붙여넣기)

import numpy as np # 2D 합성곱 연산 def conv2d(image, kernel): kh, kw = kernel.shape h, w = image.shape out = np.zeros((h-kh+1, w-kw+1)) for i in range(out.shape[0]): for j in range(out.shape[1]): out[i,j] = np.sum(image[i:i+kh, j:j+kw] * kernel) return out # 2x2 맥스풀링 def max_pool2d(fm, pool_size=2): h, w = fm.shape out = np.zeros((h//pool_size, w//pool_size)) for i in range(out.shape[0]): for j in range(out.shape[1]): out[i,j] = np.max(fm[i*pool_size:(i+1)*pool_size, j*pool_size:(j+1)*pool_size]) return out # 세로선 검출 필터 kernel_v = np.array([[0,1,0],[0,1,0],[0,1,0]]) # 6x6 숫자 '1' 이미지 (세로선) img1 = np.array([ [0,0,255,255,0,0], [0,0,255,255,0,0], [0,0,255,255,0,0], [0,0,255,255,0,0], [0,0,255,255,0,0], [0,0,255,255,0,0]]) / 255.0 fmap = conv2d(img1, kernel_v) print("특성맵 (4x4):") print(np.round(fmap, 2)) print("\n풀링 후 (2x2):") print(np.round(max_pool2d(fmap), 2)) print("\n💡 세로선이 강하게 반응했나요?")
