소리가 글자가 되는 마법: 인공지능 음성인식(Speech AI) & 스마트 비서

STEP 01 • 기초 개념 & 소리 파형 시각화

컴퓨터는 귀도 없는데 어떻게 사람의 소리를 들을까?

공기의 떨림(진동)이 마이크를 거치면 시간에 따른 전압 파형(Waveform)으로 변환되고, 초당 16,000번 숫자로 샘플링되어 컴퓨터에 저장됩니다. 반대로 글자를 읽어주는 TTS는 텍스트를 주파수 파형으로 합성하여 스피커로 출력합니다.

🗺️

이 모듈에서 배우는 것 (3줄 요약)

  1. 1단계에서 소리의 정체를 파헤쳐요: 공기의 떨림이 어떻게 숫자와 그림(파형)이 되는지 직접 만져보기 🎵
  2. 2~3단계에서 소리의 지문(특징 벡터)을 뽑고, 두 목소리가 몇 % 닮았는지 AI처럼 판정해보기 🔬
  3. 4단계에서 진짜 AI 비서 완성! 마이크로 말하면 글자로 받아쓰고 음성으로 대답해줘요 🤖

STT (Speech-to-Text: 음성인식)
사람 목소리(공기 떨림) ➔ 파형(Waveform) ➔ 0과 1 디지털 숫자 ➔ 글자(텍스트)
🔊
TTS (Text-to-Speech: 음성합성)
컴퓨터 글자(텍스트) ➔ 인공지능 신경망 ➔ 합성 파형(Waveform) ➔ 스피커 소리 출력

🎛️ 직접 만져보는 소리 실험실: 주파수 & 파형 시뮬레이터

슬라이더를 움직여 소리의 높낮이(주파수)와 크기(진폭)를 바꿔보고 스피커로 들어보세요! ✅ 성공 기준: 슬라이더를 움직일 때마다 파형 모양과 소리가 바뀌면 성공!

실시간 파형 (Waveform): Sine Wave 440 Hz (기준음 라)
수학 공식: \( y(t) = A \cdot \sin(2\pi f t) \) ● Web Audio API 실시간 연동
주파수 (소리의 높낮이) 440 Hz
50Hz (초저음) 2,000Hz (고음)
진폭 (소리의 크기/볼륨) 50 %

1. 진폭 (Amplitude) = 소리의 크기

파형의 높이(진폭)가 클수록 강한 에너지를 가지며 큰 소리(Big Volume)가 납니다. 컴퓨터는 이 값을 \(0 \sim 1.0\) 사이의 소수 숫자로 정규화하여 저장합니다.

2. 주파수 (Frequency) = 소리의 음정

1초 동안 공기가 진동하는 횟수(Hz)입니다. 진동수가 많을수록 얇고 높은 모기 소리(고주파), 진동수가 적을수록 굵고 낮은 덤프트럭 소리(저주파)가 됩니다.

3. 파형 형태 = 소리의 음색 (Timbre)

같은 440Hz '라' 음이라도 피아노와 바이올린의 소리가 다른 이유는 물결 모양(배음 구조)이 다르기 때문입니다. AI는 이 음색을 분석해 사람을 구분합니다.

sampling_rate = 16000    # 1초당 16,000번 소리 샘플링
duration = 1.5           # 1.5초 동안 지속
t = np.linspace(0, duration, int(sampling_rate * duration), endpoint=False)

# 440Hz 사인파 파형 생성: y = A * sin(2 * pi * f * t)

plt.title("440Hz 사인파 소리 파형 (Waveform)")
plt.xlabel("시간 (Time, 초)")
plt.ylabel("진폭 (Amplitude)")
plt.grid(True, alpha=0.3)
plt.show()

# 주피터 노트북에서 재생 버튼 누르고 듣기!

STEP 02 • 푸리에 변환 & 소리 지문 ID 시스템

복잡한 소리에서 '고유 ID'와 '수학적 지문' 뽑아내기

소리 파형만 보면 말의 내용을 알 수 없습니다. 수학의 고속 푸리에 변환(FFT)을 거치면 소리가 저음·중음·고음으로 분해되며, AI는 이 스펙트럼에서 5가지 대표 수치를 뽑아내 고유 소리 ID와 특징 벡터를 만듭니다!

# [2단계] 소리 파형에서 푸리에 변환(FFT)을 수행하고 5차원 고유 지문 벡터 추출하기
import numpy as np
📓 셀 2 · 지문 벡터 추출 함수 
def extract_sound_fingerprint(y, sr=16000, sound_id="VOICE-01"):
    # 1. 진폭 피크 정규화 (-1.0 ~ +1.0)
    y = y.astype(np.float32)
    peak = np.max(np.abs(y)) + 1e-12
    y_norm = (y / peak) * 0.98

    # 2. 고속 푸리에 변환 (FFT: 시간 파형 -> 주파수 스펙트럼)
    N = len(y_norm)
    win = np.hanning(N)
    X = np.fft.rfft(y_norm * win)
    freqs = np.fft.rfftfreq(N, 1/sr)
    mag = np.abs(X)

    # 3. 5대 수학적 특징 계산
    rms = float(np.sqrt(np.mean(y_norm**2) + 1e-12))             # 1) RMS 음성 에너지 크기
    zcr = float(np.mean(np.abs(np.diff(np.sign(y_norm))) > 0))    # 2) ZCR 영교차율 (자음 거칠기)

    def band_energy(f_low, f_high):
        idx = (freqs >= f_low) & (freqs < f_high)
        return float(np.sum(mag[idx] ** 2))

    low_e  = band_energy(0, 300)        # 3) 저음역 (0~300Hz, 성대의 기본 진동 주파수)
    mid_e  = band_energy(300, 3000)     # 4) 중음역 (300~3,000Hz, 모음 포만트 핵심 영역)
    high_e = band_energy(3000, 8000)    # 5) 고음역 (3,000~8,000Hz, 자음/마찰음 영역)

    # 4. 정규화된 5차원 단위 벡터 생성 (길이=1.0)
    raw_vec = np.array([rms, zcr, low_e, mid_e, high_e], dtype=np.float32)
    norm_vec = raw_vec / (np.linalg.norm(raw_vec) + 1e-12)

    return {
        "id": sound_id,
        "vector": norm_vec,
        "labels": ["RMS", "ZCR", "LowE", "MidE", "HighE"]
    }

# [3단계] 두 학생의 음성 특징 벡터로부터 코사인 유사도(Cosine Similarity)를 계산하고 일치율 판정하기
import numpy as np
📓 셀 2 · 유사도 계산·판정 함수 
def compute_voice_similarity(feat_a, feat_b):
    """
    두 음성 특징 벡터 A, B 사이의 코사인 유사도를 계산합니다.
    공식: cos(theta) = (A · B) / (||A|| * ||B||)
    """
    norm_a = np.linalg.norm(feat_a) + 1e-12
    norm_b = np.linalg.norm(feat_b) + 1e-12
    cosine_sim = np.dot(feat_a, feat_b) / (norm_a * norm_b)
    
    # 0.0 ~ 1.0 클리핑 및 백분율(%) 환산
    percentage = float(np.clip(cosine_sim, 0.0, 1.0)) * 100.0
    
    # 교육용 자동 판정 기준
    if percentage >= 90.0:
        verdict = "🏆 [판정: 90% 이상] 동일 인물이거나 발음이 거의 일치합니다! (화자/단어 일치)"
    elif percentage >= 70.0:
        verdict = "👥 [판정: 70~89%] 같은 단어이나 목소리 톤(음색)이 서로 다른 두 학생입니다!"
    else:
        verdict = "❌ [판정: 70% 미만] 서로 다른 단어를 말했거나 목소리 특징이 완전히 다릅니다!"
        
    return percentage, verdict

        return f"'{query}'라고 말씀하셨군요. 언제든 필요한 내용을 물어보세요!"

중·고등학교 정보/인공지능 교과 및 방과후 수업, 교원 연수에 바로 활용할 수 있는 차시별 타임라인과 수업 운영 팁입니다.

📘 [1차시] 소리의 원리와 파형 시각화 45분
  • 0~10분: "컴퓨터는 귀도 없는데 어떻게 들을까?" 도입 발문
  • 10~25분: 피아노 '라(440Hz)' 소리 코드로 만들기 & 주파수 체험
  • 25~38분: 소리의 3요소(진폭, 주파수, 음색) & 무지개 스펙트로그램 시각화
  • 38~45분: 소리 지문 ID 부여 및 2차시 음성 유사도 대결 예고
📗 [2차시] 2인 음성 유사도 대결 & 스마트 비서 45분
  • 0~10분: 음성인식(STT) 원리와 OpenAI Whisper 모델 소개
  • 10~22분: [핵심 실습] 2인 학생 목소리 유사도 대결 (코사인 유사도 일치율 채점)
  • 22~33분: [프로젝트 1] "간장 공장 공장장" 발음 채점 게임 🎮
  • 33~42분: [프로젝트 2] 우리 반 스마트 음성 비서 만들기 🏫
  • 42~45분: 청각 장애인을 위한 자막 안경과 AI 윤리 토론
