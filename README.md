**코딩을 한 번도 안 해본 고등학교 1학년 학생도 OK!** 🙌

- **이런 분께 추천해요**
  - "AI가 궁금한데 수식 보면 머리가 아파요" 하는 학생 🙋
  - 코딩 첫걸음을 재밌게 떼고 싶은 고1, 중학생, 비전공자
  - 수업 시간에 바로 쓸 인터랙티브 자료를 찾는 선생님
- **준비물은 딱 하나!** 크롬(또는 엣지/사파리) 브라우저만 있으면 돼요. 설치할 게 전혀 없어요.
- **어렵게 느껴지면?** 각 단원은 **비유(이야기) → 체험(시뮬레이터 만져보기) → 코드(파이썬 따라하기)** 순서로 구성돼 있어요. 코드를 몰라도 시뮬레이터부터 가지고 놀다 보면 개념이 자연스럽게 잡혀요!

### 🌟 핵심 특징
1. **토스(Toss) 스타일 미니멀 디자인**: 군더더기 없는 순백색 카드 UI와 Pretendard 타이포그래피, 직관적인 슬라이더 조절로 수업 집중도를 극대화했습니다.
2. **시뮬레이터 하단 실행형 파이썬 코드 내장**: 웹에서 눈으로 확인한 계산 원리를 바로 아래 다크 테마 코드 카드로 확인하고, **[코드 복사]** 버튼 하나로 구글 코랩에 붙여넣어 실행할 수 있습니다.
3. **5대 도메인 완전 정복**: 숫자(머신러닝) → 픽셀(비전) → 패턴(CNN) → 문장(자연어) → 파형(음성)으로 이어지는 체계적 로드맵을 제공합니다.

## 🧮 [선생님 지도 가이드 1] 컴퓨터 비전 5단계 수학 커리큘럼

파이썬과 컴퓨터 비전이 처음인 학생들을 지도할 때 아래 순서대로 개념을 전개하면 가장 효과적입니다:

### 1단계: 컴퓨터의 눈 (픽셀과 2차원 행렬)
- 컴퓨터는 화면을 볼 때 모양이 아니라 **바둑판 격자(픽셀)**에 적힌 **$0 \sim 255$ 숫자(밝기)**만 봅니다.
- $0$ = 가장 어두운 검은색, $255$ = 가장 밝은 흰색, 중간 숫자 = 회색.

### 2단계: 테두리(Edge) 찾기의 수학: "어떤 셀을 뺄까?" (오른쪽 셀 vs 아래쪽 셀)
- 테두리는 **"숫자가 갑자기 확 바뀌는 경계선"**입니다.
- **👉 오른쪽 셀과의 뺄셈 (가로 방향)**: $| \text{오른쪽 셀}(r, c+1) - \text{현재 셀}(r, c) |$
  - 좌우 밝기가 바뀔 때 큰 숫자가 나와 **'세로선(수직 테두리)'**을 감지합니다.
- **👇 아래쪽 셀과의 뺄셈 (세로 방향)**: $| \text{아래쪽 셀}(r+1, c) - \text{현재 셀}(r, c) |$
  - 상하 밝기가 바뀔 때 큰 숫자가 나와 **'가로선(수평 테두리)'**을 감지합니다.
- **✨ 종합 테두리**: $\max(\text{오른쪽 차이}, \text{아래쪽 차이})$
  - 세로선과 가로선이 합쳐져 **완전한 물체 외곽선**이 완성됩니다.
- 평평한 곳: $|0 - 0| = 0$, $|255 - 255| = 0$ (차이 없음 $\rightarrow$ 선 아님)
- 경계면: $|255 - 0| = 255$ (차이가 극대화 $\rightarrow$ **테두리 발견!**)

### 3단계: 임계값(Threshold)의 원리 (기준선 정하기)
- 그림자나 먼지 때문에 차이가 $10 \sim 30$ 정도 나는 미세한 잡티를 걸러내기 위해 기준선을 세웁니다.
- $\text{차이값} \ge \text{Threshold}$ 이면 $255$(흰색 선 인정), 미만이면 $0$(검은색 버림).
- 임계값이 너무 낮으면 잡티투성이, 너무 높으면 선이 끊어집니다.

### 4단계: 웹캠 & 실제 이미지 테두리 인식
- Canny 에지 검출기를 통해 하한/상한 임계값을 조절하며 내 손/얼굴과 사물의 윤곽선 추출을 실시간으로 확인합니다.

### 5단계: [징검다리] 테두리(공간 뺄셈)에서 움직임(시간 뺄셈)과 크기 필터링으로!
- **테두리**: 공간 차이 ($|\text{오른쪽 픽셀} - \text{현재 픽셀}|$)
- **움직임 감지**: 시간 차이 ($|\text{현재 프레임 픽셀} - \text{배경 도로 픽셀}|$)
- 배경과 차이나는 픽셀 덩어리의 **면적(크기, `MIN_AREA`)**을 비교하여:
  - **작은 크기 (`MIN_AREA = 100`)**: 오토바이, 사람까지 모두 감지
  - **큰 크기 (`MIN_AREA = 450 이상`)**: 작은 오토바이는 무시하고 큰 자동차만 골라서 감지!

## 🤖 [선생님 지도 가이드 2] 자연어 처리 & AI 에이전트 커리큘럼

### 1단계: LLM과 AI 에이전트의 정의
- **LLM (거대 언어 모델)**: 수억 권의 책과 인터넷 글을 학습하여 다음에 올 가장 자연스러운 단어를 예측하는 거대한 언어 두뇌.
- **AI 에이전트 (AI Agent)**: 단순히 수동적인 대화만 하는 챗봇을 넘어, **목표(Goal)**를 가지고 주변 문서나 환경을 **탐색(Perceive)**하고, **판단(Reason)**하여 문제를 해결하고 **행동(Act)**하는 자율적 인공지능.

### 2단계: 문장 분석과 토큰화 (Tokenization)
- 컴퓨터는 글자를 그대로 이해하지 못하므로, 문장을 의미 있는 작은 조각(**토큰**)으로 쪼개고 고유한 **숫자 번호(ID)**로 변환합니다.

### 3단계: 단어 빈도 벡터 & 코사인 유사도 (Cosine Similarity)
- 문장을 단어들의 등장 빈도에 따라 **공간 위의 화살표(벡터)**로 표현합니다.
- 두 문장의 관련성은 화살표 사이의 **사잇각($\theta$)**으로 계산합니다:
  $$\cos(\theta) = \frac{\vec{A} \cdot \vec{B}}{\|\vec{A}\| \|\vec{B}\|}$$
  - $\theta = 0^\circ \implies \cos(0^\circ) = \mathbf{1.0}$: 같은 주제, 가장 관련 깊은 정답 문장!
  - $\theta = 90^\circ \implies \cos(90^\circ) = \mathbf{0.0}$: 전혀 상관없는 딴소리!

### 4단계: 검색 증강 생성(RAG)과 인공지능 독서의 유용성
- **환각(Hallucination) 방지**: LLM에게 문학작품이나 학교 규정집을 쥐여주고, 코사인 유사도로 가장 유사한 원문 조항(근거)을 먼저 찾은 뒤 답변하게 합니다.
- **인공지능을 활용한 독서(AI Reading)의 가치**:
  - 소설 속 등장인물(점순이, 어린 왕자, 여우)과 직접 가상 인터뷰를 하며 속마음과 작가의 의도를 능동적으로 파악.
  - 방대한 학교생활규정집이나 매뉴얼에서 내가 원하는 조항을 1초 만에 근거와 함께 정확히 찾아냄.

### 5단계: [핵심 개념] 데이터(Data) vs AI(Brain) 분리와 교실 API 보안 관리
- **📚 데이터 영역 (Data / Knowledge Base)**: AI가 읽고 기억할 책과 원문 텍스트. 데이터가 없으면 AI는 소설 속 내용을 알지 못해 엉뚱한 거짓말(환각)을 지어냅니다.
- **🧠 AI 두뇌 영역 (AI / LLM Reasoning Engine)**: 데이터를 읽고 질문에 맞춰 생각하고 대답하는 독해자. AI가 없으면 검색된 문장 조각만 보여줄 뿐, 사람처럼 맥락을 짚어 대화하지 못합니다.
- **✨ 나만의 AI 만들기**: 학생이 좋아하는 소설이나 자작글을 입력하고, 캐릭터 페르소나(이름, 성격, 엄격한 근거 규칙)를 부여하여 자신만의 에이전트를 완성합니다.
- **🚨 수업 후 API 키 파기(Shred) 원칙**: 교사용 Google API 키는 브라우저 세션(`sessionStorage`)에만 임시 보관되며, 수업이 끝나면 **[수업 종료: API 키 즉시 파기]** 버튼을 눌러 메모리에서 완전 삭제하고 안전한 오프라인 모드로 전환합니다.

## 🧠 [선생님 지도 가이드 3] CNN(합성곱 신경망) 6단계 수학 커리큘럼

엑셀 실습 파일(`CNN_계산과정_숫자판별_정리본.xlsx`), 웹 시뮬레이터(`cnn_classifier_simulator.html`), 코랩 노트북(`실습)_CNN_계산과정.ipynb`)을 함께 활용할 때의 지도 가이드입니다:

### 1단계: 픽셀 행렬과 데이터 정규화 ($0 \sim 255 \rightarrow 0.0 \sim 1.0$)
- 컴퓨터가 눈으로 보는 $6 \times 6$ 이미지는 총 36개의 밝기 숫자입니다.
- 큰 숫자를 그대로 다루면 계산이 폭발하므로, $255$로 나누어 소수로 만듭니다 (`=A5/255` $\leftrightarrow$ `img / 255.0`).

### 2단계: 특징 탐지기(Filter / Kernel)의 원리
- **세로선 필터 (|)**: $\begin{bmatrix}0&1&0\\0&1&0\\0&1&0\end{bmatrix}$ (숫자 1의 척추 획 감지)
- **가로선 필터 (-)**: $\begin{bmatrix}0&0&0\\1&1&1\\0&0&0\end{bmatrix}$ (숫자 2의 지붕/바닥 획 감지)
- **대각선 필터 2종 (/, \)**: 꺾임 및 대각 획 감지

### 3단계: 합성곱(Convolution)과 수용장(Receptive Field)
- $3 \times 3$ 필터가 $6 \times 6$ 위를 1칸씩 미끄러지며(Stride=1) 원소별 곱셈 합을 구합니다 ($4 \times 4$ 특성맵 완성).
- 시뮬레이터에서 특성맵 셀을 마우스로 가리키면 6×6 원본의 $3\times 3$ 영역(수용장)이 빨간 테두리로 하이라이트됩니다!

### 4단계: 맥스풀링(Max Pooling 2×2, Stride=2)
- $4 \times 4$를 4등분하여 가장 강한 값(최대값)만 남깁니다 ($2 \times 2$ 크기 축소).
- 데이터 양을 75% 줄이고, 위치가 살짝 삐뚤어져도 강한 특징을 놓치지 않는 '위치 불변성'을 학습합니다.

### 5단계: 드롭아웃 및 1D 벡터 평탄화 (Flattening)
- 4개 풀링맵에서 대표 특징 2개씩을 뽑아 $1 \times 8$ 1차원 벡터 $X$로 정렬합니다.

### 6단계: 완전연결층(Dense Layer) 가중치 곱($W$)과 편향($b$) & 최종 판별
- 세로선 특징($x_1, x_2$)에는 **양수 가중치(+3)**를 곱해 점수를 높이고,
- 가로/대각 특징($x_3 \sim x_6$)에는 **음수 가중치(-3)**를 곱해 점수를 깎습니다.
- 편향 $b = +5$를 더한 뒤:
  $$\text{Score} \ge 0 \implies \text{숫자 1 예측!}, \quad \text{Score} < 0 \implies \text{숫자 2 예측!}$$
