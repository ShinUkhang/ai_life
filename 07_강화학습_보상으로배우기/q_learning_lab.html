보상으로 배우는 AI

정답을 알려 주지 않아도 AI가 배울 수 있을까요? 게임 AI, 로봇, 자율주행이 쓰는 강화학습은 "잘하면 +점수, 못하면 −점수"만으로 스스로 길을 찾습니다. 오늘은 사탕 뽑기 게임으로 원리를 익힌 뒤 미로를 탈출하는 AI를 코딩하고, 점수 규칙(보상)을 바꾸면 AI의 행동이 어떻게 달라지는지 추리합니다.

사탕 뽑기 게임

뽑기 기계가 3대 있어요. 사탕(+1점)이 나올 확률은 기계마다 다르지만 비밀입니다. 20번만 뽑을 수 있다면, 사탕을 가장 많이 받으려면 어떻게 해야 할까요? 먼저 내가 해 보고, 같은 기계를 AI에게 맡겨 비교해 봅시다.

남은 기회 20번
기계의 [뽑기] 버튼을 눌러 보세요.
👤 나: 사탕 / 뽑은 수0 / 0
🤖 AI: 사탕 / 뽑은 수0 / 0

이 확률만큼은 일부러 아무 기계나 뽑아 봐요.

한 번 결과를 점수(Q)에 얼마나 크게 반영할까?

↑ AI가 쓰는 변수와 규칙 (코드 실험실 미로에도 똑같이 나와요)

원리: Q표 한 줄

게임에서 AI는 기계마다 "이 기계는 얼마나 좋을까?"라는 점수 Q를 기억했어요(처음엔 모두 0). 한 번 뽑을 때마다 아래 한 줄로 점수를 고칩니다.

# 새 Q = 옛 Q + 학습률 × (받은 점수 − 옛 Q) ← "예상보다 좋았으면 올리고, 나빴으면 내린다" Q[기계] += ALPHA * (r - Q[기계])

직접 계산해 보기 — ALPHA = 0.5. 처음(Q = 0) 기계 B를 뽑아 사탕이 나왔어요(r = 1). 다음에 또 B를 뽑았더니 꽝(r = 0). Q[B]는 어떻게 변할까?

정답 확인
① 0 + 0.5 × (1 − 0) = 0.5   ② 0.5 + 0.5 × (0 − 0.5) = 0.25. 게임의 [🤖 1번 뽑기]를 누르면 같은 계산이 화면에 나와요.

미로에서는 "앞으로 받을 점수"가 더해져요

코드 실험실의 미로는 한 번 움직여서 끝나지 않아요. 그래서 칸마다, 방향마다 Q를 두고, 다음 칸에서 기대할 수 있는 가장 좋은 점수까지 더합니다. 게임 공식에 GAMMA * max(Q[다음 칸])만 붙은 거예요.

Q[s][a] += ALPHA * (r + GAMMA * max(Q[s2]) - Q[s][a])
변수뜻비유
ALPHA학습률: 새 경험을 얼마나 크게 반영할까1차시 경사하강법의 보폭과 같은 역할
EPSILON탐험률: 일부러 아무거나 해 볼 확률늘 가던 식당 vs 새 식당 도전
GAMMA할인율: 미래 점수를 얼마나 중요하게 볼까 (0~1) — 미로에서만"지금 놀기" vs "나중을 위해 공부하기"

코드 실험실

이번엔 게임보다 한 단계 어려운 미로 탈출이에요. 지도는 코드 안의 MAP에 있고(S 출발 · G 도착 +10 · X 함정 −10 · # 벽), 게임과 같은 Q 공식에 미래 점수(GAMMA)가 더해져요. 대문자 변수만 바꿔 실행하고 변수 실험 기록표의 마지막 줄(결과 · 걸음 수 · 점수)을 비교하세요. 그래프는 판마다 받은 점수(학습 곡선)입니다.

M1연습량과 학습률기본

EPISODES를 300 → 20, 다시 300으로 돌리고 ALPHA를 0.5 → 0.01

힌트
ALPHA = 0.01이면 한 번 경험할 때 Q가 1%만 바뀌어요. 300판으로는 도착점의 +10이 출발점까지 전해지지 못합니다. 1차시에서 학습률이 너무 작으면 손실이 천천히 줄던 것과 같은 현상이에요.
M2탐험의 대가기본

EPSILON을 0.1 → 0.5. 최종 결과와 마지막 50판 평균 점수를 따로 비교

힌트
탐험을 많이 하면 연습 중에 함정에도 자주 빠져서 점수가 낮아요. 하지만 Q표에는 "가장 좋은 길"이 기록되어 있어서, 탐험 없이 가 보면 같은 길을 찾습니다. 새로운 것을 시도하는 데에는 비용이 든다는 것 — 사람도 마찬가지죠.
M3미래를 보지 않는 AI심화

GAMMA를 0.9 → 0.5 → 0.0

힌트
GAMMA = 0이면 GAMMA * max(Q[s2])가 0이 되어, AI는 "이번 한 걸음의 점수"만 봐요. 도착점의 +10은 바로 옆 칸까지만 전해지고 출발점에서는 보이지 않아 헤매게 됩니다.
M4보상을 잘못 설계하면핵심

STEP_REWARD를 -1 → -2 → -5

힌트
도착 길 = 7×(−5) + 10 = −25, 함정 길 = (−5) + (−10) = −15. AI 입장에서는 함정에 일부러 빠지는 게 "점수가 더 높은" 정답이에요! AI는 우리가 원한 것이 아니라 점수 규칙을 따릅니다. 이것을 "보상 해킹(reward hacking)"이라고 불러요.
